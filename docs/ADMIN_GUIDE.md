# 管理员手册

## 状态

功能开发中。最终手册将覆盖首次登录改密、用户/角色、课次、实验室策略、开放规则、停用课次、设备、审批/驳回/强制取消、代签到签退、统计导出和审计查询。

所有危险操作必须在界面明确显示对象与影响；驳回和管理员取消必须填写原因。
